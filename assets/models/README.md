# 模型文件夹

Tripo 等工具生成的模型放在这里，文件名和要求见 [docs/素材清单.md](../../docs/素材清单.md)。

- `raw/`：原始导出文件，原样保存，不直接进游戏。
- 处理过（减面、缩小贴图、统一大小和朝向）的版本放在这一层，游戏只加载这些。

上传方法：在 GitHub 网页上打开 `dev` 分支的这个文件夹，点 **Add file → Upload files**，把 `.glb` 文件拖进去，再点 **Commit changes**。
