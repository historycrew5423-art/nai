## 二、为什么让 Unity 做电影片段，而不是再做一个游戏
- 两边做同一个游戏，等于每样只做了一半；最后只能交一个。
- 观众用手机扫码玩，网页版加载快、已经在跑。Unity 打包的网页版大，iPhone 打开慢。
- 视频不用在手机上实时画，可以直接用原始的高精度模型（9 万面、2K 贴图）、开满光影和后期，正好发挥 Unity 的长处。参考视频那种电影感，靠这个最接近。
- 成品用在三个地方：路演开场、小红书视频、网页游戏里的过场。

## 角色模型（在仓库的 `assets/models/raw/`，都是 Tripo 导出的 GLB，没有骨骼和动作）
- `fantasy.glb`：黄色圆头角色，深蓝金边披风、羽毛三角帽。**罗密欧**。
- `wedding-dress.glb`：穿白色羽毛婚纱的公主。**朱丽叶**。
- `minotaur.glb`：牛头人，暗红条纹衣服、佩剑。**提伯尔特**，朱丽叶的表哥。
- `rabbit.glb`：黄色兔子头人，暗红条纹衣服、佩剑。**茂丘西奥**，罗密欧的朋友。
- 模型高约 1 个单位，脚底在高度 0。放进场景时按 1.6 到 1.8 米高缩放。视频不用在手机上跑，原始的高精度模型直接用，不用减面。
- 没有骨骼，所以动作用整体移动和简单的关键帧做：走路时轻轻上下起伏、左右微晃；转身、跪下、倒下用整体旋转和下沉表现。不要给模型绑骨。
- 怪物和场景的参考图在 `assets/ref/`（乐器怪、鸟嘴面具的客人、三头犬、亡魂，以及两张概念图）。预告片里可以出现乐器怪和三头犬，它们是"被两家的仇恨附身的东西"。

## 技术方案
1. **Unity 版本：** 优先 Unity 6 LTS，用 URP。在中国用 Unity Hub 下载编辑器如果失败或特别慢，就改用团结引擎（Unity 中国版）和团结 Hub，同样用 URP。先检查这台 Mac 的芯片和剩余磁盘空间，告诉我要下载多大。
2. **Codex 的 Unity 插件（Unity 官方文档）：** 先把 Codex CLI 更新到最新，再运行：
   - `codex plugin marketplace add Unity-Technologies/unity-agent-plugin`
   - `codex plugin add unity@unity-agent-plugin`
   - 用 `codex plugin list` 确认 unity 已安装、已启用。
   - 在 Unity 编辑器里打开 Project Settings > AI > Unity MCP Server，确认 Unity Bridge 在运行、Integrations 里的 Codex 已配置；再用 `codex mcp list` 检查。编辑器打开后要重启一次 Codex 才连得上。
   - 如果用的是团结引擎、官方插件连不上，就只用插件里的 Unity 知识，场景和脚本靠写文件来做，让我在编辑器里点运行，再把截图发给你。
3. **导入 GLB：** 在 Package Manager 里按名字添加 glTFast（`com.unity.cloud.gltfast`），然后把四个 GLB 拖进 Assets。
4. **场景：** 用 ProBuilder 或基本形状搭四处地方：舞会大厅（吊灯、烛台、深红帷幔、石柱）、月光下的花园和阳台（石栏杆、玫瑰丛、藤蔓）、白天的石板广场（拱廊、喷泉）、墓室（石台、成排的蜡烛、拱顶）。用 Asset Store 或别处的素材，必须是许可证允许的，并在日志里写清来源和许可证。
5. **光影和后期：** URP 的 Volume 加 Bloom、Vignette、Color Adjustments、Film Grain、Depth of Field；光柱可以用半透明的锥体或粒子做。色调：烛光暖金、冷蓝的阴影。
6. **镜头：** 用 Cinemachine 和 Timeline 做推拉、环绕、跟随的运镜，每个镜头 3 到 6 秒，贴近人物。
7. **导出视频：** 用 Unity Recorder（`com.unity.recorder`）输出 MP4。过场视频要压到每段 3 MB 以内，可以降码率。
