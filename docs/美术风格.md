# 美术风格（10-31 00:45）

> 用户问：要不要做图来控制游戏的美术风格？

> 这份文件是所有人共用的规则。出图、做模型、搭场景、写代码都照这个来。

## 一、风格一句话
**3D 动画电影质感的欧洲童话冥界：** 动物头和圆头的可爱角色，穿着做工细腻的文艺复兴到 18 世纪服装，在烛光照亮的哥特式地下世界里，用音乐对付博斯画里那种乐器怪物。

已经定下风格的四张角色图（用户 10-30 深夜做的）：黄色圆头角色、婚纱公主、牛头人、兔子头人。后面所有图都向它们看齐：造型可爱夸张，材质写实（丝绒、刺绣、金属、羽毛），比例接近真人，不是 Q 版大头小身子。

## 二、颜色
| 用在哪 | 颜色 | 色值 |
|---|---|---|
| 背景、远处的黑暗 | 近黑的紫 | `#14121c` |
| 阴影、夜色 | 墨蓝 | `#22263a` |
| 石头地面 | 暗灰紫 | `#3a3640` |
| 衣服、帷幔 | 暗红丝绒 | `#6e1e2a` |
| 金线、画框、烛台 | 暖金 | `#d9a441` |
| 烛光、音符 | 橙黄的光 | `#ffb85c` |
| 亡魂、冥河的反光、经验萤火 | 冷青 | `#7fe3d8` |
| 婚纱、出口的光 | 暖白 | `#f2ede4` |

大面积是暗色（前三行），亮色只用在要让人注意的地方。

## 三、光
- 烛光暖、月光和亡魂的光冷，暗处很暗。
- 角色身上要有一圈边缘光，从暗背景里跳出来。
- 最亮的地方只有三种：主角、音符、出口的光。

## 四、游戏画面要看得清（俯视约 45 度的镜头）
- 地面暗、对比低、花纹少。精致的东西放在场地边缘和背景里。
- 主角是画面里最暖、最亮的颜色。
- 每种怪的轮廓都不一样，看形状就知道是哪种；颜色偏冷或偏暗红，被打中闪白。
- 音符是发光的暖金色，经验萤火是冷青色，两者不要混。
- 不要血腥，不要恐怖的脸，不要文字和商标，不要照片一样写实的人脸。

## 五、出图的共同前缀
每条出图提示词前面都加上这一段，保证风格一致：

> 3D 动画电影风格，材质细腻写实（丝绒、刺绣、金属、羽毛），欧洲文艺复兴到 18 世纪的童话感，烛光的暖金色和冷蓝色阴影，暗调的电影光，角色有边缘光，可爱而古怪，不血腥不恐怖，没有文字和水印。

1. **游戏画面概念图**（最重要，Kiro 照着做网页）

2. **冥界场景概念图**（给队友和 Codex）
