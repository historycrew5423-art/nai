# 第二部的故事：海岛画风（10-31 11:35，提议，等用户选）

> 用户（11:30）："怪物的做成3d，美术风格这个，原来的场景也保留。这个可以做成另一个西方故事也行，想想"，附了 4 张截图，是抖音视频里那个游戏《漂岛奇航 Drift Isles》。
> 所以：罗密欧与朱丽叶的四幕（烛光、油画）保留不动；照截图的画风，另做一个西方故事，当第二部。

## 截图里的画风
- 阳光很足的白天，颜色饱和：碧蓝的海水，浅水处一圈白色浪花，米黄色沙滩，鲜绿的草地。
- 一层一层的灰色石头小山，山顶是绿的；棕榈树、圆滚滚的树和灌木；木头码头、帆船、石头拱门遗迹、木牌子、宝箱。
- 造型圆润、像玩具一样的卡通 3D，没有复杂的贴图，靠颜色块和柔和的阴影；远处有一点雾。
- 镜头在主角身后斜上方，主角小，世界大。
- 这种画风正好适合用代码做：地面、水、山、树都能用简单形状加颜色拼出来，手机也跑得动。

## 推荐：莎士比亚《暴风雨》（1611）
**一句话：** 罗密欧和朱丽叶坐船离开维罗纳，被魔法师普洛斯彼罗掀起的暴风雨打翻，漂到一座会唱歌的魔法岛上。

- **接得上第一部：** 第一部改写的结局里，朱丽叶说"那就走吧，离开维罗纳"。第二部就从这条船开始。角色、打法、名画卡全都照用。
- **和"用歌打怪"最配：** 原剧里岛上的精灵爱丽儿就是靠音乐引人走路的；怪物卡利班有一句名台词：这岛上满是声音和甜美的乐曲。
- **同一个作者：** 整个游戏可以叫"莎士比亚的两场戏"，路演时一句话讲清楚。
- **名画（都是公有领域，放进游戏前再核对细节）：** 米莱斯《费迪南被爱丽儿引诱》（1850）、沃特豪斯《米兰达——暴风雨》（1916）、霍加斯《〈暴风雨〉中的一幕》（约 1735）。照第一部的办法，用我们的角色重画成油画。
- **怪：** 被暴风雨召来的海浪精灵、螃蟹和海鸟；Boss 是卡利班。亡魂可以改成岛上的精灵。
- **今天做得完的量：** 先做一幕"漂岛"，约 60 秒，最后打卡利班，幕末一幅名画。开始画面上可以选"第一部 罗密欧与朱丽叶"或"第二部 暴风雨"。

## 另外两个选择
- **《奥德赛》（荷马）：** 奥德修斯坐船在海岛之间漂流，海妖塞壬用歌声迷人，独眼巨人当 Boss。帆船和海岛很配，名画有沃特豪斯《尤利西斯与塞壬》（1891）、透纳《尤利西斯嘲弄波吕斐摩斯》（1829）。缺点：和罗密欧接不上，要换主角。
- **《鲁滨逊漂流记》（笛福，1719）：** 你比赛前最早的点子。荒岛求生很配画风，但怪物和名画比较少。
