## 二、策划草案

你说的"升级三选一、子弹变多、往后射"，在手机上已经是一类很成熟的玩法。只做这些，评委会觉得眼熟，也容易碰到"与已上线产品极度相似"那条规则。所以核心按你说的来，再加几样别人没有的。

**核心循环（你的设计）：** 选角色 → 进场，怪从四面八方涌来，越来越多 → 角色开枪打怪，怪掉经验 → 升级时画面变慢，从三个技能里选一个（子弹变两颗、往后射等）→ 坚持 2 分钟，最后来一个 Boss → 累计击杀数解锁新皮肤。

**我加的三样**（建议先做前两样，第三样看时间）：
1. **被围得越紧，升级越快。** 经验不光靠杀怪，身边的怪越多，经验涨得越快。选完技能那一刻，以你为中心炸开一圈，清掉身边一波怪。你想要的"快打不完时突然升级、一下打爆"，就从碰运气变成每局都会发生。玩家还得自己赌：躲远一点稳一些，还是让怪贴上来换更快的升级。
2. **怪潮会叠起来。** 怪挤不动时会爬到别的怪身上，堆成一堵墙压过来。这只有 3D 做得出，投屏路演很好看，观众也记得住。
3. **皮肤会改子弹。** 每款皮肤除了外观，子弹的样子和一个小特性也不同，比如穿透、冰冻。击杀数存在手机上，观众为了解锁下一款会再玩一局。

**角色先做 3 个，操作各不相同：**
- **A：** 只用一个摇杆走，自动瞄准开枪。最简单，给第一次玩的观众。
- **B：** 左手走，右手瞄准，伤害更高。
- **C：** 按住蓄力，松手打出一发能穿透的大炮。

每个角色还有一个自己的大招按钮。

**主题跟着小怪定。** 你打算把怪做成什么样？没想好的话，我有个建议：主角是几个 AI 小助手，怪是成群的 bug，三选一的技能卡做成"提示词卡"。现场都是做 vibe coding 的人，路演一开口就有共鸣。

**开源资源：** 新规定允许参考开源的场景、地图和源码。主角可以用 CC0 许可（免费、可商用）的人物包，比如 Quaternius、KayKit 这类，它们自带骨骼和动作，能省掉最费时间的绑骨。用之前我会逐个核对许可和动作，来源写进仓库，提交表上如实勾选。玩法代码我自己写，不套别人的游戏模板。

## 三、iPhone 和横屏

- iPhone 的 Safari 不允许网页强制横屏或全屏（[说明](https://gist.github.com/fozzedout/5e77925381991a9570151550992baf14)）。所以竖着拿时，画面显示"请横过来"；横过来后画面固定 16:9，多出来的地方留黑边。
- 观众要先关掉控制中心里的"竖排方向锁定"才能转屏。横屏时 Safari 的地址栏会占一点地方；"添加到主屏幕"后再打开，就接近全屏，路演时用这个方式。
- github.io 在国内一般能打开，但有时慢。今晚第一版出来后，请你不开代理、用手机流量试一次。慢的话我们再加一个备用网址。
