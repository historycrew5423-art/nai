# 罗密欧与朱丽叶 · 奶蛙缝合版（naiwa）· 最终版

VibeHacks #06 参赛作品《罗密欧与朱丽叶》的一条分支：在 v0.2 的四幕剧情（舞会 → 阳台 → 决斗 → 墓室）上，缝进了《勇者奶蛙》的抽象玩法和四种梗小怪。代码全部由 AI（Kiro，模型 Claude Opus 5.5）编写。

- **试玩：** https://historycrew5423-art.github.io/nai/naiwa/ （手机横屏、竖屏都能玩；电脑用键盘鼠标）
- **主线版本《莎士比亚的两场戏》：** https://historycrew5423-art.github.io/nai/

## 玩法
- 罗密欧（黄色圆头角色）张嘴喷字打怪：“哈”是普通字；“嘎”弹射、“跌”打趴、“塞”爆炸、“水”冲开并减速、“噗”穿透，喷特殊字时会喊奶龙的口头禅。
- 梗小怪：咕咕嘎嘎企鹅（肘击）、我的刀盾狗（举刀砍）、香蕉猫（哭着头槌）、OIIA 猫（转圈撞人）。每种都有自己的叫声，被打倒时按各自的梗飞走。
- 肥嘟嘟技能：喷字攒满能量后点🦘按钮，袋鼠用老外口音喊“你的胆子真是肥嘟嘟的！”，画面里的小怪全被吹成气球爆掉。
- 梗是一个一个“上新”的：开头只有刀盾狗和“哈”，之后企鹅、香蕉猫、OIIA 猫和各种喷字隔几秒才出来一个，越往后越热闹；大招前后会安静一下，不会吵成一锅粥。
- 变身大奶蛙捧腹大笑：全屏声波清怪；倒下时也会立刻捧腹大笑、满血复活（很难死）。
- 走几步自动闪身步；第三幕提伯尔特学牛来低头冲撞，撞到障碍物会眼冒金星。
- 俯视、第三人称、第一人称三种视角。

## 操作
| | 手机 | 电脑 |
|---|---|---|
| 走 | 横屏：左手按住拖；竖屏：一根手指在哪里按住拖都行 | WASD / 方向键 |
| 瞄准 | 横屏：右手拖；竖屏：第二根手指拖（不碰都会自动喷） | 鼠标 |
| 肥嘟嘟 | 右下角🦘按钮（喷字攒满后发光） | F |
| 变身捧腹大笑 | 右下角「变身」按钮 | V |
| 闪身步 | 走路时自动 | 空格（走路时也自动） |
| 切换视角 | 右上角「视角」 | C；第一/第三人称时 Q / E 或鼠标转身（先点一下画面） |

手机横屏、竖屏都能玩，同一个网址，转过来画面会自动重排。

## 文件
- `index.html`、`src/`、`vendor/three/`（three.js r187，MIT）、`assets/`：游戏本体，纯静态网页，不需要构建。
- `缝合说明.md`：这一版改了什么、每个素材的来源和许可。
- `部署说明_给WorkBuddy.md`：怎么部署、怎么放进 GitHub。
- `scripts/`：处理模型、合成语音的脚本（参考用，游戏运行不需要）。
- `Play-Windows.bat`、`server.mjs`：在 Windows 电脑上本地试玩（双击 bat，会自动打开浏览器）。
