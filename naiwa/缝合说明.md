# 缝合版说明（2026-10-31）

本目录是《罗密欧与朱丽叶》v0.2（`_交付_给AI改`，即 GitHub `nai` 仓库 `dev` 分支 10-31 早上的版本）的副本，在它上面缝进了《勇者奶蛙》的玩法和四种 3D 梗小怪。原目录没有改动。
它和线上主线版（10-31 中午起改名《莎士比亚的两场戏》，加了封面、《暴风雨》、3D 怪物、存档）是**两条分开的线**：主线之后的改动这里没有，这里的改动主线也没有。部署方法见 `部署说明_给WorkBuddy.md`。

## 这一版改了什么

### 一、小怪换成两个新模型（用户 10-31 上传的 Tripo 模型）
- **刀盾狗**（`assets/models/minion-b.glb`）：替换鲁特琴怪、鼓怪（鼓怪更大、偏红）。靠近罗密欧时把刀举到脑后再往前劈，同时喊“我的刀盾（What the dog doing?）”。
- **咕咕嘎嘎企鹅**（`assets/models/minion-a.glb`）：替换鸟嘴面具客人、号角怪（远程）、墓室亡魂（偏蓝）。靠近时扭身蓄力、转身肘击，同时叫“咕咕嘎嘎”。
- 原始模型各约 85 MB、190 万面，减到约 1.1 万面、贴图 1024 JPG，各约 730 KB，保留 Tripo 的 41 根骨骼。
- 动作在 `src/minions.js`：代码摆骨骼，烘焙 8 帧走路 + 8 帧攻击，每帧一个实例网格；几百只同屏只多 32 次绘制。

### 二、勇者奶蛙的玩法（`src/naiwa.js` + `src/game.js`）
- **喷“哈”字**：罗密欧射出的音符换成从嘴巴高度喷出的“哈”字。每喷一次播一个“哈”音节（从奶蛙爆笑原声里自动切出来，共约 40 段）。后来又加了五种特殊字，见第八节。
- **提伯尔特学牛来低头冲撞**：逼近 → 低头蓄力，地上出现红色箭头线（前 60% 时间会跟着罗密欧转，之后锁死）→ 沿直线冲 → 撞到井、马车、木箱等障碍物就“咚！”撞晕 1.8 秒，头上转星星，这时多吃 50% 伤害。血量过半后蓄力更快、会连撞两次。被撞中会扣血并被顶飞。
- **变身大奶蛙捧腹大笑**：第一幕第 8.5 秒自动变身一次（演示），之后每次用完冷却 18 秒（右边的「变身」按钮，或键盘 V）。变成大奶蛙（`assets/models/bigfrog.glb`，骨骼让它前仰后合），镜头拉近，左上角弹出捧腹大笑动图并播放笑声；3.4 秒里放 5 圈全屏声波，画面里的怪都挨打并被震开，提伯尔特被笑晕。期间不掉血。

### 三、更容易（10-31 用户要求）
- 受到的伤害全部只算 60%（小怪、号角酸音、提伯尔特冲撞），墓室亡魂扣朱丽叶“安稳”的速度也降到 60%。
- **倒下立刻捧腹大笑复活**：血掉光时不结束游戏，立刻变成大奶蛙捧腹大笑（不占变身冷却），满血复活，周围的怪被笑声震开。可以无限复活。网址加 `?norevive=1` 可以关掉，恢复原来的倒下画面。
- 第四幕朱丽叶的“安稳”扣光仍然是原版的悲剧结局（那是剧情分支，不是罗密欧倒下）。

### 四、两只新猫小怪（10-31 下午用户上传的 Tripo 模型）
- **香蕉猫**（`assets/models/minion-c.glb`）：走路时香蕉身子左右晃、香蕉尖像果冻一样甩；攻击是往后一仰、整根香蕉往前“头槌”。被打倒时哭着翻跟头飞走（“呜哇——”）。
- **圆滚滚的 OIIA 猫**（`assets/models/minion-d.glb`，长得像猫头鹰的那只）：走路像企鹅一样左右摇；攻击是拉长身子原地转一整圈撞人（OIIA OIIA），血厚一点。被打倒时越转越快“螺旋升天”。
- 两个原始模型都没有骨骼，Tripo 的贴图展开又碎，普通减面卡在 10~20 万面。所以换了做法（`scripts/bake_cats.mjs`）：先把高模“绕一圈拍下来”做成一张 1024 的圆柱贴图，再只按位置减面到 8000 / 6500 面，文件 300 / 480 KB。动作是代码直接挪顶点（`src/minions.js` 的 `bananaDeform` / `oiiaDeform`）。
- 四种梗怪混着出：第一幕刀盾狗、香蕉猫、OIIA 猫、企鹅都有；后面几幕也把两只猫加进去了。

### 五、每种小怪都有自己的梗音效，并且分层（`src/sfx.js`）
- 企鹅“咕咕嘎嘎”、刀盾狗“我的刀盾（What the dog doing?）”、香蕉猫哭声、OIIA 猫“OIIA OIIA”。打人时叫一声（同种怪最多 2.2 秒一次），**被打倒时一定会抢着叫**，头上冒短字，屏幕下方出字幕。
- 声音分三条线：
  - **主角线**（喷“哈”、奶龙口头禅、闪身步、捧腹大笑、肥嘟嘟）：居中、最响。主角一开口，小怪线自动压低（“哈”压一点点，口头禅压到 25%，捧腹大笑压到 18%）。主角说口头禅时不放“哈”，一句话说完整。
  - **小怪线**：同一时间只叫一只，两只之间留 0.12 秒空；更重要的才能顶掉正在叫的（第一次登场 > 被打倒 > 打人）。按怪在画面左边还是右边偏声像，离得远就小声；再削掉一点低频和人声最亮的那段频率，给主角让位置。
  - **效果线**：嗖、啵、嘭这些合成的小音效。最后接一个压缩器，几十只怪一起倒也不会爆音。
- 字幕也分层：下面一行大黄字是主角说的，上面一行小一点的彩色字是小怪叫的。

### 六、前 10 秒就上梗（“冷开场”）
- 默认不放开头的序幕对话，点“开始”直接开打（想看序幕在网址加 `?prologue=1`）。
- 第 0 秒：奶蛙先笑一声、闪白、字幕“哈哈哈哈哈哈！”。
- 第 0.4 秒：四面同时走进画面一群梗怪（企鹅、香蕉猫、OIIA 猫、刀盾狗），每种第一次出现时一只一只播它的招牌叫声 + 字幕。
- 一直在喷字，特殊字会喊“嘎巴跌！”“嘎脚塞！”“嘎嘎滴啦水～”“嘟噗！”，被打倒的怪按自己的梗飞走，右边有“连哈”计数，10 / 25 / 50 连时出大字。
- 第 5 秒左右第一次“肥嘟嘟”，第 8.5 秒自动变身大奶蛙捧腹大笑一次（演示给玩家看，之后按 V 或右边按钮）。
- 第一幕前 20 秒的怪比原来多（9 只起步），并且生成得近，两三秒就走进画面。

### 七、灵活转向 + 闪身步
- 走路时主角立刻转向走的方向（转得快，转弯时身子往里歪），站着不动时才转向瞄准的方向；子弹照样往瞄准的方向喷。
- **闪身步**：每走 6 米自动往旁边闪一步（左右轮流，带一点往前），0.2 秒滑 2.4 米，闪的时候不挨打，身后留 4 个青色残影，配“嗖”声和“闪身步！”字（喊“闪身步”的原声最多 2.6 秒一次）。电脑上按空格也能闪。

### 八、七种喷字，效果各不一样
| 字 | 颜色 | 效果 | 主角喊 |
|---|---|---|---|
| 哈 | 金 / 粉 | 普通 | 每口一个“哈” |
| 嘎 | 青 | 弹到旁边的怪，连弹两次 | — |
| 跌 | 紫 | 打趴 1.5 秒（侧躺抽搐，不走也不打人） | 嘎巴跌！ |
| 塞 | 橙 | 炸开一圈（半径 1.9 米） | 嘎脚塞！ |
| 水 | 蓝 | 把一片怪冲开，并减速 2.5 秒（变蓝） | 嘎嘎滴啦水～ |
| 噗 | 绿 | 大泡泡，一路穿过 5 只怪 | 嘟噗！ |

每 3 口里有 1 口是特殊字；口头禅最多 1.5 秒喊一句。Boss 不会被打趴、冲走。

### 九、肥嘟嘟（喷满 5 秒触发）
- 左上角“肥嘟嘟”进度条：累计喷满 5 秒，屏幕中间弹出袋鼠横幅“你的胆子真是肥嘟嘟的！”，画面里（16 米内）的小怪全被吹成粉色气球，飘起来一个接一个“啵”地爆掉（给经验、算连杀）；提伯尔特会被笑晕一下、掉点血。
- 声音是**老外口音**（10-31 用户要求）：让微软的美式英语男声 Andrew 念按英语拼读写的中文 “Nee duh dahn-zuh, jen shur, fay doo doo duh!”，出来就是老外说中文的味道（`assets/audio/feidudu.mp3`，约 2.9 秒）；说完再跟一声尖一点的 “Fay doo doo!”（`assets/audio/feidudu-echo.mp3`，Guy 的声音）。横幅下面也打出这行拼读小字。生成脚本：`scripts/gen_feidudu.py`（edge-tts）。
- 录音没加载上时，用浏览器里的英语声音现场念同一句拼读，一样是老外口音。想换成别的录音（比如找到原梗视频的声音），直接用同名文件覆盖 `assets/audio/feidudu.mp3`。

### 十、第一人称 / 第三人称（更立体）
- 右上角「视角」按钮或键盘 C 切换：俯视 → 第三人称 → 第一人称。网址加 `?cam=1` / `?cam=2` 直接用第三 / 第一人称开局。
- 第三人称：镜头越过右肩跟在背后；第一人称：在主角眼睛的位置，看不到自己。画面中间有准星。
- 操作：WASD / 左摇杆按镜头方向走（上 = 往前）；转身用鼠标（点一下画面锁定鼠标）、Q / E 键，手机上右手左右拖。自动喷前方扇形里最近的怪，背后贴身的怪也会顺手喷；按住鼠标左键就往准星方向喷。
- 字子弹、萤火这些立牌改成每帧正对镜头，哪种视角都不会变扁；飘字按离镜头远近缩放，贴脸时不会糊满屏幕。
- 捧腹大笑时第一人称会临时退到背后，好看见大奶蛙。对话、选卡、暂停时自动松开鼠标。

## 怎么跑

和原版一样：在本目录运行 `python -m http.server 8000`，浏览器打开 `http://127.0.0.1:8000/`。不要双击 `index.html`。
测试参数照旧：`?auto=1` 自动跳过对话、`?god=1` 不会死、`?act=3` 直接从第三幕开始、`?debug=1` 显示帧数；新增 `?norevive=1` 关掉捧腹大笑复活、`?cam=1` / `?cam=2` 第三 / 第一人称开局、`?prologue=1` 开头先放序幕对话。
键盘：WASD 走、鼠标瞄、V 变身捧腹大笑、空格闪身步、C 切换视角（第一/第三人称时 Q / E 或鼠标转身）。
